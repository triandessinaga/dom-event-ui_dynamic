LAB 9

Arrow Function, find & filter

Cara penulisan fungsi yang lebih ringkas. Wajib dipahami karena kode Smart Retail penuh dengan pola ini.

📖 Konsep

  • Arrow function: const fn = (x) => x * 2 sama dengan function fn(x) { return x * 2; }
  • find: array.find(item => item.id === 1) — kembalikan satu item yang cocok
  • filter: array.filter(item => item.category === "minuman") — kembalikan array baru yang lolos syarat
  • reduce: array.reduce((acc, item) => acc + item.qty, 0) — akumulasi semua item jadi satu nilai
  • Di Smart Retail: const rupiah = (n) => "Rp" + n.toLocaleString("id-ID"), products.find(p => p.id === id), filter produk berdasarkan pencarian & kategori

CARA LAMA vs CARA MODERN

❌ Cara Lama (verbose)
function rupiah(n) { return "Rp" + n.toLocaleString("id-ID"); } var produk = arr.find(function(p) { return p.id === 1; }); var minuman = arr.filter(function(p) { return p.category === "minuman"; });
✅ Cara Modern (arrow function)
const rupiah = (n) => "Rp" + n.toLocaleString("id-ID"); const produk = arr.find( (p) => p.id === 1 ); const minuman = arr.filter( (p) => p.category === "minuman" );

State & Render — Inti Dynamic UI

Pola paling penting dalam membangun UI yang responsif. Semua perubahan tampilan di Smart Retail mengikuti alur ini.

📖 Konsep — Alur Wajib

  • 🖱️ User Action — pengguna melakukan sesuatu (klik, ketik)
  • 📦 Ubah State — data JavaScript diperbarui (state.cart.push(...))
  • 🖼️ Render — panggil fungsi render untuk update DOM (renderCart())
  • ⚠️ State TIDAK PERNAH diubah langsung dari DOM — harus lewat variabel JavaScript dulu
  • Di Smart Retail: const state = { cart:[], search:"", category:"all", darkMode:false, titleChanged:false } adalah satu-satunya sumber kebenaran
